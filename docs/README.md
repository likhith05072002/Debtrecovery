# Project Documentation

This folder contains a human-readable walkthrough of the `debtcollector` project.

Files in this folder:

- `PROJECT_REPORT.md`: complete project report with architecture overview, folder tree, and grouped file-by-file descriptions.

Scope notes:

- The report covers application source, frontend source, migrations, scripts, tests, and deployment/config files.
- Generated or vendor-heavy directories such as `venv/`, `frontend/node_modules/`, `__pycache__/`, and compiled frontend assets are summarized instead of documented file by file.
